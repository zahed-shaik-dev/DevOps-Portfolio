# Zahed Hussain Shaik — DevOps Interactive Portfolio

A minimalist, corporate-styled DevOps portfolio built with React, Tailwind CSS and Lucide Icons.

## Run locally

```bash
npm install
npm run dev
```

Then open the Vite URL shown in the terminal.

## Production build

```bash
npm run build
npm run preview
```

## Included interactions

- Interactive CI/CD pipeline with stage-specific terminal logs
- Tool health-check animation: `[PENDING] → [CHECKING] → [HEALTHY]`
- Project console with cloud/tool filters and expandable architecture traces
- Cloud / scale / compliance architecture estimator with YAML output
- Chaos Monkey easter egg with simulated failures and self-healing
- Responsive dark/light theme
- GitHub and project repository links

## Notes

The estimator is intentionally illustrative and does not calculate live cloud pricing.
Contact details are taken from the supplied brief; the phone number remains masked as supplied.
